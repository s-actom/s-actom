Use the global skill `impeccable`.

Task: perform a final polish pass on $ARGUMENTS.

Rules:
- Do not redesign the product.
- Do not change business logic, routing, APIs, data models, or copy strategy unless the issue is directly UI clarity.
- First inspect the current UI/code before proposing changes.
- Focus only on spacing, alignment, visual hierarchy, typography, contrast, responsive behavior, interaction states, loading/error/empty states, and production finish.
- Avoid generic AI UI patterns: purple gradients by default, nested cards everywhere, weak gray text, random glows, default Inter-only look, cramped padding, inconsistent radius/shadows.
- Prefer minimal, high-impact changes.
- Before editing, state the exact files you intend to touch and why.
- After editing, summarize changed files and validation performed.
