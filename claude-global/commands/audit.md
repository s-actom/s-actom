Use the global skill `impeccable`.

Task: audit $ARGUMENTS for frontend/UI quality.

Do not edit files unless explicitly asked.

Check:
- visual hierarchy
- spacing rhythm
- typography
- contrast and readability
- responsive behavior
- touch targets
- hover/focus/loading/error states
- accessibility basics
- generic AI UI patterns
- unnecessary visual noise
- inconsistent components

Return:
1. Critical issues
2. Important improvements
3. Optional polish
4. Exact recommended files to inspect or change
